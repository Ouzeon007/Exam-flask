# -----Application E-Commerce Flask-----

# Description du Projet

Cette application web est une plateforme e-commerce permettant aux utilisateurs de parcourir, rechercher et acheter des produits en ligne.

# Fonctionnalités Principales

- Authentification des utilisateurs : Système de connexion
- Catalogue de produits : Affichage , recherche de produits par non
- Détails des produits : Page  pour chaque produit avec description détaillée puis posiblite de l'ajouter au panier
- Panier : Ajouter , suprimer des produit et vider le panier , utilisation de session
- Upload d'images : ajout d'images pour les produits


# Installation

1- telecharger le dépôt git

2- Créer un environnement virtuel :
   python -m venv .venv

3- Activer l'environnement virtuel :
   - Windows : `.venv\Scripts\activate`
   - Linux/Mac : `source .venv/bin/activate`

4- Installer les dépendances :
   pip install -r requirement.txt



# Exécution
flask run --debug
